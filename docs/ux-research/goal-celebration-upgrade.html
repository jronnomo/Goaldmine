The Assay — a goal completion that is an artifact, not an event

No modal. No dismiss. The achieved page renders proud from the top of the viewport, permanently. A one-shot flourish plays on first view; if it is missed, nothing is lost — the settled state is the design, and the animation only re-times elements that are already in place. Every frame below is drawn at a 390px phone column, in both palettes, coal first (the founder's daily palette), then cream.

How to read this file
Tokens are the real ones, lifted from src/app/globals.css and applied as CSS custom properties on .dark / .light. The Bullseye is the real geometry from src/components/Bullseye.tsx: viewBox="0 0 32 32", four filled circles at cx=cy=16 with r=15/11/7/3, alternating var(--target) and var(--target-fg). It is scale-pure, so it is rendered here at 224px with no other changes.
Small var(--muted) callouts run alongside each element carrying spacing, type size, touch-target height and token name. Nothing in this file touches source — it is a drawing.
⚠ Substitutions & provisional values
Type is substituted. Geist and DM Serif Display are not available offline, so this file uses system-ui for body/UI and Georgia, "Times New Roman", serif everywhere the production design would use DM Serif Display (the objective, readiness numerals, medal monograms, section headings on this page). Georgia is wider and lower-contrast than DM Serif Display — do not judge final type from this file; the objective in particular will set tighter and more vertical in production.
Every numeric value here is provisional pending playtest. Sizes, durations, stagger offsets and stroke widths carry a ⚠ with a range. They are starting points for a device check, not specifications. The content values (98 days, 8→89, 7/9, +700 XP) are the Mt. Elbert reference case.
Measured contrast — why this composition is shaped the way it is
PairCoal (dark)Cream (light)Consequence for this design
--accent on --target 1.35:1 1.16:1 Gold and rust are luminance twins. They cannot touch. The gold annulus is separated from the rust glyph by a 14px band of plain --background ⚠(10–18px). Cream is the failing case — verify there first.
--target-fg inside --target 3.09:1 — Graphic only. The rings read fine as shape at 224px, but 3.09:1 is below text minimums — never place text inside the rust rings in coal.
--accent on --accent-soft — 4.14:1 Fails AA in cream. So the GOAL COMPLETE eyebrow sits on plain --background — no soft-gold pill, chip or wash anywhere in the ceremony.
--accent on --background 8.56:1 4.95:1 Passes — eyebrow, annulus, medal fill, primary CTA.
--success on --background 6.88:1 5.46:1 Passes — the ✓ on met targets.
--muted on --background 5.72:1 5.44:1 Passes — sublines, values, captions, permanence line.

Frame 5
Before / after — the angular-size argument
Angular diameter scales linearly with size, so the 224px hero subtends exactly 7× the visual angle of the shipped 32px emoji at any viewing distance — and covers ~49× the retinal area. In absolute terms on a 390-CSS-px-wide phone (1 CSS px ≈ 0.18mm): the emoji is ~5.8mm → ~0.6° at arm's length; the hero is ~41mm → ~2.5° at 90cm and ~4° at 55cm ⚠(approximate; depends on device and posture). Below ~1° a mark is read as a label; at 2.5–4° it is read as an object. That is the entire difference between a trophy icon and a monument.

Open questions for the call
What this mockup cannot answer
1. The gap in cream. 14px is drawn here; on a real display at real brightness the gold ring and rust glyph may still bleed into each other. Check cream outdoors before anything else.
2. Hero size on a small phone. 224px + 268px of hero row pushes the objective toward the fold on a 667px-tall viewport. If it crowds, the tuning move is the hero row's height, not the glyph.
3. Georgia is lying to you about the objective. DM Serif Display at 36px sets narrower; long objectives that wrap to three lines here may set to two in production.
4. Flourish duration. 640ms reads generous on desktop and may read slow on a phone that has already loaded the page once. 520ms is the likely landing spot.
