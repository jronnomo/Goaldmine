Goaldmine · /progress complete overhaul

Pixel mockup · 10 Aug 2026 · chosen direction: Frequency Stack, Ruled (Direction C + grafts G1/G2/G3) · every panel must be inspected in both themes and in grayscale

What this is. Six 390px frames rendering the chosen /progress IA with the real globals.css token block and the real Phase 2A fixtures. It is a specification artifact, not a prototype: nothing fetches, nothing animates, and the only script is the two toggles. Card, strip, lid, CeilingRule, ProgramBlockBand, SeamLine, CappedMarker and EmptyState are hand-compiled from the shipped components so the chrome matches the markup that will actually ship.

Real vs projected. Panel 1 is the honest state on Program day 1 — every number in it is derived from phase2a-spec.ts through progressFor, and where the engine returns null the panel shows no numeral at all. Panel 2 is a projection to ~20 Sep and is marked as such on the frame, in the panel title and in a banner; not one of its numbers is in the database today. Panel 3 is a synthetic legacy tenant (no Program, one deadlift goal) drawn to prove the stack degrades by getting shorter rather than by orphaning anything. Panel 4 is a real zero-row invited user. Panels 5 and 6 are component studies.

The two toggles. Theme (top right) cycles system → light → dark by writing data-theme on :root, exactly as ThemeToggle.tsx does; the file defaults to light. Both themes are normative — a mockup that is only correct in one is not correct. Grayscale check applies filter: grayscale(1) to every frame. That is the shipped acceptance test (UXR-PV-05): the palette is iso-luminant, so a grayscale screenshot must lose nothing. Press it on every panel. If a distinction disappears, that distinction was never information.

Reading the annotations. Dashed-left grey text is annotation, never product UI. A small ⚠ beside a value means the px is provisional — the research gave a range and this file picked a point inside it. Every one is listed with its range in the footer table. Do not read any ⚠ value as settled.

The whole argument for Direction C is this panel. Five sections simply do not render — band, Seam Strip, both rules, Effort — and the stack just gets shorter. The three-channel ▲cap. (1) CappedMarker's ▲cap text on the row; (2) SeamLine gains rule?: number, ~6 lines, drawing a dashed horizontal at the cap so the flat tail reads as pinned, not stalled; (3) the Recharts ReferenceLine plus capped points rendered as flat-topped 6×2px bars instead of r=3 — a shape channel, so it survives the grayscale check. E · fill token — open decision

Neither the synthesis nor the chosen direction names the fill token. Both candidates are drawn. Press the grayscale button: they are indistinguishable in weight, so this is a grammar decision, not a legibility one.

var(--accent) — per the ASCII key

var(--foreground) — per R-2, "not a progress grammar"

Divs, not SVG (R-17). CeilingRule is divs by explicit sign-off and ReachMeter renders five discrete segments as spans. SeamLine is SVG only because it draws an arbitrary polyline into a non-uniformly stretched box; six fixed-size discrete marks have neither an arbitrary path nor a non-uniform scale.

Do NOT use the ● ■ ▲ triad here. That is the goal-identity vocabulary; these slots are sessions within one goal's target. Reusing it would collide with goal identity on a page that renders three goals.

Not a progress grammar. GateArc and ReadinessLadder were rejected as "a third progress grammar next to Bullseye and ReachMeter." The Seam Strip shows no progress toward any target — it shows the categorical outcome of six past sessions. Its kin are MarkLane, BadgeWall, StatusPill. Spec it that way so nobody re-litigates it.

A11y deviates deliberately. An <ol> with an sr-only span per slot, not role="img" and never role="progressbar": a progress bar semantically implies monotonic advance, and this metric's defining property is that it can go down. The count and target are real DOM text, not an aria-label — findable, translatable, and structurally incapable of drifting out of sync with the pixels.

⚠ device check — the single number most in need of one is the 10px date micro-label in --muted on coal. If it undershoots, bump to 11px or --foreground before shrinking the column.

Zero motion. No transition on any part of this component, ever — a band is a fact, not an event. And the one candidate strike moment, a tier crossing its target, is rejected on meaning: the value can un-cross tomorrow, and celebrating it converts the mirror into a slot machine.

Both frames: no bar (a cliff metric never gets one — the engine returns 1 at exactly 25 and 0 the instant it drops below, so a bar would render 24 and 3 identically), no arrow, no --danger, no ↓. The eyebrow carries --warning; the copy stays --foreground, because --warning as body text is a 4.6:1 AA edge.

The absence of a color is the message. A reading that goes down is stated as a reading, with both dates and both numbers. Nothing about the presentation says "you failed" — the canary's job is to report, and the coach's job is to interpret.

The cheapest strong idea in Pillar 1: render Baseline.notes on the row only when the delta is negative. This is not a "conditions matched ✓" indicator — the schema cannot support one; Baseline has exactly one free-text field and no rpe, testOrder or fatigued. It is simply displaying the field that exists, and it is the app's only fatigue channel. It also creates the right loop: the coach starts writing conditions into notes because they get read.

Maintenance is not a stored flag. It is derived exactly once, as start !== null && start === target.target. There is no kind, no direction: "maintenance".

Sort exception. Baseline rows sort by weight descending — except a maintenance row in BELOW FLOOR, which pins to position 1. That is a state-dependent sort, not a state-dependent defaultOpen; the banned hazard is a lid flipping under the finger on revalidate, not content reordering. ⚠ verify.

Substitutions in this artifact

  • Fonts — system sans for Geist, Georgia for DM Serif Display. Metrics, and therefore every wrap point above, will shift once the real faces load. --font-display appears in exactly two places: the gallery h1 (annotation chrome) and the milestone ceremony numeral (product, sanctioned).
  • Recharts — the two charts are hand-drawn SVG reproducing the house chassis (grid --border 3 3, axes --muted 11px with no tick or axis line, line --accent 2px, dot r=3, the two-layer role="img" + aria-hidden idiom). They are stand-ins, not renderings.
  • --danger is defined in the token block for fidelity and used nowhere. Banners cap at --warning.
  • Opacity — bg-[var(--border)]/60 and bg-[var(--muted)]/70 are compiled to color-mix(). Nothing in this file is differentiated by reduced opacity, which fails the 3:1 non-text threshold.
  • Not modelled — the BottomSheet drill-in behind the Seam Strip (sessions newest-first, with the attemptCap: 5 qualifying span bracketed), the title= hover fallback, and the overflow list behind Show all 6 →.
